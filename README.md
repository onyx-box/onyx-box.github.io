# Onyx Box Portfolio

React + TypeScript + Vite, routing EN/PL, dynamic project content and GitHub Pages deployment.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

W repozytorium ustaw: `Settings → Pages → Source: GitHub Actions`.

## Treści

Projekty są w `src/content/projects/index.ts`, a obrazy w `public/images/projects/`.

## Routing

- `/` i `/pl/`
- `/projects` i `/pl/projekty`
- `/projects/:slug` i `/pl/projekty/:slug`
- `/privacy` i `/pl/prywatnosc`
